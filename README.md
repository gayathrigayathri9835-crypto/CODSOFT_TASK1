Java Number Guessing Game – CodSoft Internship Task 1

About the Project

This is a Java-based Number Guessing Game developed as part of the CodSoft Internship Task 1. The player has to guess a randomly generated number between 1 and 100.

Features

- Random number generation.
- Limited attempts to guess the number.
- Hints such as Too High and Too Low.
- Score calculation.
- Replay option.
- Final score display.

Technologies Used

- Java
- VS Code
- Java Scanner
- Random number generation

How to Run

1. Download or clone this repository.

2. Open the project in VS Code.

3. Open the terminal.

4. Compile the program:
   
   "javac NumberGame.java"

5. Run the program:
   
   "java NumberGame"

Game Instructions

- Guess a number between 1 and 100.
- You have limited attempts.
- The game provides hints to help you guess.
- Guess correctly to earn points.
- Choose Y to play again or N to exit.
